# FoodCatalog

FoodCatalog - мобильное Android-приложение, разработанное на языке Kotlin для просмотра каталога блюд.

## Функциональные возможности

Приложение содержит четыре категории:

- Завтраки
- Основные блюда
- Десерты
- Напитки

При выборе категории открывается список из трёх блюд. Пользователь может выбрать блюдо и просмотреть его название и краткое описание.

## Технологии

- Язык программирования: Kotlin
- Среда разработки: Android Studio Quail 4 (2026.1.4)
- Интерфейс: XML (View)
- minSdk: API 26
- targetSdk: API 37
- compileSdk: API 37

## Структура приложения

Приложение состоит из трёх Activity:

1. MainActivity - отображение категорий блюд.
2. DishListActivity - отображение списка блюд выбранной категории.
3. DishDetailActivity - отображение подробной информации о блюде.

Для переходов между экранами используются явные Intent с передачей данных через putExtra().


## Тестирование

Приложение проверено на эмуляторе Medium Phone с Android 17 (API 37.1).

Для регистрации событий приложения применяется Logcat. Журнал событий сохранён в файле `logs/logs.txt`.
